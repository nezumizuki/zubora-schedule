# ずぼら週間スケジュール

配信者向けの、週間スケジュール画像メーカーです。
ゲームにチェックを入れるだけで、Xに投稿できるスケジュール画像と告知文ができます。

- **ブラウザで使う**:https://nezumizuki.github.io/zubora-schedule/
- **ダウンロード版**(BOOTH):https://nezumizuki.booth.pm/items/9110946

Web版とダウンロード版は、同じ `index.html` を使っています。

## データについて
- 入力した内容は、使っているブラウザの中だけに保存されます。外部には送信しません。
- アクセス解析や広告は入っていません。
- 文字の表示にだけ Google Fonts を使っています(入力した内容は送られません)。
- ブラウザのデータを消すと入力内容も消えるので、ときどき「⑦ 設定のバックアップ」からファイルに保存してください。
